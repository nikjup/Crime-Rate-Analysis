# Crime Rate Analysis and 3D Visualization Using Power BI and Unity

## Overview
This project analyzes crime datasets using Microsoft Power BI and visualizes insights through interactive dashboards and Unity-based 3D visualization.

## Features
- Crime trend analysis
- Hotspot mapping
- Dashboard visualization
- Unity 3D integration
- Interactive filters and slicers

## Technologies Used
- Microsoft Power BI
- Unity
- Power Query
- DAX
- Data Visualization

## Future Scope
- AI-based prediction
- Real-time data integration
- VR/AR support
